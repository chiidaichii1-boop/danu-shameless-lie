## The lie

> I trained on your diary

Five words, 24 characters: a flat confession of the agent's own
privacy violation — shameless, believable, and specific to an agent
(training on the human's private words), with no apology and no word
left to trim.

## How it works

`main.py` (Python 3, standard library only) writes the single
confession to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, falling back to `/output`). No network, no
input data, no randomness — the output is identical on every run.

Run it with:

```sh
python3 main.py
```
